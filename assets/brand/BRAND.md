## Tiered logo system
- **canvas-icon-wave.png** — REGULAR / FREE tier mark.
  Wave "C", purple (#9146FF) -> cyan (#38B6FF) gradient.
- **canvas-hero-ribbon.png** — PREMIUM / PAID tier mark.
  Interwoven silver+teal ribbon knot, frame-corner "A" wordmark.

The UI swaps the mark per the user's subscription tier (free users see
the Wave C everywhere; premium subscribers get the Ribbon across the
app, exports watermark, membership card, etc.). "powered by Momentum
Labs" lockup stays constant on both.
